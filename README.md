# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Директория `pkg` содержит файлы бэкенда.

Директория `pkg/api` содержит директорию `pkg/api/db` и файлы:
-addtask.go
 файл отвечает за обработчик добавления задачи в функции addTaskHandler
 проверки даты в функции checkData
 отправку ответа в виде JSON в функции writeJson
 отправки ошибки в виде JSON в функции WriteError
 обработчик получения задачи в функции GetTaskHandler
 обработчик обновления задачи в функции UpdateTaskHandler
 обработчик удаления задачи в функции DeleteTaskHandler
 
-api.go
 файл отвечает за обработку веб-запросов в функции Init
 по запросу `/api/nextdate` срабатывает функция nextDayHandler, которая обрабатывает отправку следующей даты
 по запросу `/api/task` срабатывает функция taskHandler, которая обрабатывает методы POST, GET, PUT и DELETE
 при методе POST срабатывает функция addTaskHandler
 при методе GET срабатывает функция GetTaskHandler
 при методе PUT срабатывает функция UpdateTaskHandler
 при методе DELETE срабатывает функция DeleteTaskHandler
 по запросу `/api/tasks` срабатывает функция tasksHandler, которая обрабатывает получение нескольких задач
 по запросу `/api/task/done` срабатывает функция doneHandler, которая обрабатывает отметку выполнение задачи
-tasks.go
 файл отвечает за функцию tasksHandler, которая обрабатывает получение нескольких задач

Директория `pkg/api/db` содержит файлы:
-task.go
 файл отвечает за добавление задач в функции AddTask
 получения задач в функции Tasks
 получения задачи по id в функции GetTask
 обновлении задачи в функции UpdateTask
 удалении задачи в функции DeleteTask
 обновлении даты задачи в функции UpdateDate

Директория `pkg/constant` содержит файлы:
-constant.go
 файл отвечает за содержание констант

Директория `pkg/date` содержит файлы:
-date.go
 файл отвечает за сравнение времени в функции AfterNow
 получение следующей даты в функции NextDate

Директория `pkg/db` содержит файлы:
-db.go
 файл отвечает за создание таблицы scheduler в базе данных scheduler.db

Директория `pkg/server` содержит файлы:
-server.go
 файл отвечает за запуск сервера
